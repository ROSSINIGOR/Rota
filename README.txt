ROTA - gravador de rota (Kotlin, sem dependencias externas)

1) Abra esta pasta no Android Studio (File > Open) e aguarde o Gradle sincronizar.
2) Build > Build Bundle(s) / APK(s) > Build APK(s).
3) O APK fica em app/build/outputs/apk/debug/app-debug.apk
4) Copie para o celular, instale (permita "fontes desconhecidas") e conceda a localizacao.

Pela linha de comando (com JDK 17 e Android SDK instalados): gradle assembleDebug
